# Security Policy

## Reporting a vulnerability

If you find a security issue in NOVA, **do not open a public issue** about it. Please report it privately so we can fix it before it is disclosed.

Send your report to the maintainers by opening a **private vulnerability report** via GitHub:

> Repository → **Security** tab → **Report a vulnerability**

## What to include

- The affected component (backend, frontend, auth, WebSocket, calls...).
- A clear description of the issue.
- Steps to reproduce, if possible.
- The impact you believe it has.

## Our commitment

- We will acknowledge your report promptly.
- We will keep you updated as we work on a fix.
- We will not disclose the issue publicly until a fix is released.

## Safe harbor

We will not pursue legal action against researchers who report vulnerabilities in good faith, following this policy, without exploiting them beyond what is necessary to demonstrate the issue.
